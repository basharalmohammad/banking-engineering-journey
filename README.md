# Banking Engineering Journey

My 12-month path from beginner to full-stack software engineer, specializing in banking and financial systems.

## Goal
I'm building the skills to design, build, test and deploy production-style enterprise applications, with a focus on what matters most in finance: correctness, data integrity, security and traceability. This repo is the public record of that work, from the first Java exercise to the final banking capstone.

## What I'm learning
- **Backend:** Java, Spring Boot, Spring Security, Spring Data JPA, REST APIs, Maven
- **Databases:** Oracle SQL and PL/SQL, PostgreSQL
- **Frontend:** HTML, CSS, TypeScript, React, Next.js
- **Engineering:** Git, automated testing, Docker, CI/CD, Kafka, observability
- **Banking domain:** double-entry ledgers, payments, idempotency, reconciliation, ISO 20022

## How this repo is organized
One folder per week (`week-01/`, `week-02/`, ...), each with its exercises and a short `NOTES.md` on what I learned and what I still need to work on. Portfolio projects live in their own repositories, linked below.
